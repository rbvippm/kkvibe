旗舰厅个人中心改版 PRD

对照旧版 5 弊（定位摇摆、资金双重割裂、留白浪费、纯图标、VIP 弱反馈）， 新版用「身份 + VIP 成长 + 一张钱包 + 活动条 + 三条增长 Banner」收口。 下图为当前原型，Banner 展示招募主播稿；每条线指向对应功能的文案总结。

旧版 5 弊

  1. 定位摇摆：个人中心既不像主页，也不像钱包页。
  2. 资金双重割裂：总资产和钱包卡两套数字，用户要猜哪笔是真余额。
  3. 留白浪费：首屏空、信息密度低，增长位被挤出视野。
  4. 纯图标：宫格难认，常用能力靠猜。
  5. VIP 弱反馈：只有等级，没有成长进度和下一档目标。

新版 5 优

  1. 身份一眼可见：头像、金刚号、社交数据先回答「我是谁」。
  2. VIP 成长可视化：VIP1 → VIP2 进度条 + 晋级流水。
  3. 一张钱包闭环：总资产、冻结额度、充提兑落在同一张卡。
  4. 活动条前置：运营入口不再藏进宫格。
  5. 三条增长 Banner：邀请好友 / 招募主播 / 邀请代理，可滑动轮播。
对照「定位摇摆」 01 顶栏工具让位给身份

未上滑时左上角扫一扫、右侧客服 / 设置；上滑后头像 + 昵称吸顶，扫一扫挪到客服前。工具不和身份抢第一眼。

对照「定位摇摆」 02 身份一眼可见

头像、昵称 EZ、金刚号 EZ888888（可复制）、动态 / 收藏 / 关注 / 粉丝横排。点资料卡进个人主页，复制号不跳页。

对照「VIP 弱反馈」 03 VIP 成长可视化

冰蓝 VIP 卡展示 VIP1 → VIP2、晋级流水 ¥59.00/1,500.00 与「VIP特权」。等级不再是孤立标签，成长路径可见。

对照「资金双重割裂」 04 一张钱包闭环

总资产、偏好法币、显隐眼睛、全部钱包在上头；卡内只留一笔大金额 + 冻结额度 + 充提兑。浅暖白底不抢戏，充值钮才是重点。

对照「留白浪费」 05 活动条前置

「活动中心，尽享福利 / 参与活动」贴在钱包下方，运营入口不再沉到宫格或更多功能。浅杏色底，避免和钱包叠成一块重彩。

对照「纯图标」 06 八宫格带文字

账单、投注、资产明细、金刚银行、邀请好友、直播中心、意见反馈、关于我们，一律图标 + 中文名，不用猜。

对照「留白浪费」 07 三条增长 Banner

本图为第 2 张「招募优质主播入住」整图（最高分成 99%）。第 1 张邀请好友、第 3 张邀请代理；右下指示器横排，约 4 秒轮播。

对照「留白浪费」 08 更多功能下沉

收款方式、直播中心、邀请好友、代理邀请落到 Banner 下方，角标提醒待办。次要能力不占首屏，主路径让给身份、钱包和增长。

旗舰厅「我的」需求说明

路由 mobile-mine（/mobile/mine）。本页是现金会员的个人中心，与贵宾厅 /mobile/vip-club/mine 共用组件，但钱包与资金能力隔离：本页只讲旗舰厅。 改版目标不是再堆入口，而是先让用户看清「我是谁、我什么等级、我有多少钱、我能参加什么、我能拉谁」。

一、功能逻辑

  1. 个人中心按「身份 → VIP 成长 → 一张钱包 → 活动条 + 8 宫格 → 三条增长 Banner → 更多功能」组织，解决旧版定位摇摆和首屏留白。
  2. 资金只保留一套数字：总资产按偏好计价法币展示，冻结额度是各现金钱包冻结金额折合合计；充值 / 提现 / 兑换都从这张卡出发。
  3. 增长分三条独立路径：邀请好友赚钱、招募优质主播入住、邀请代理拿返佣；活动中心单独一条，不和宫格抢位置。
  4. 贵宾厅同骨架但不走充提兑，不在本页展开。

二、交互行为

  1. 点扫一扫：无独立扫码页，提示「扫一扫即将开放」。上滑超过约半个头像后，顶栏出缩小头像 + 昵称，扫一扫移到客服前；滑回顶部还原。
  2. 点资料卡进个人主页；点金刚号旁复制只复制 EZ888888，成功提示「已复制金刚号」，失败提示「复制失败，请手动长按复制」。
  3. 点 VIP 卡进 VIP 详情。点总资产旁眼睛：总资产与冻结额度一并变为 ****。点刷新转一圈后更新金额。点全部钱包打开钱包 Sheet。
  4. 点充值 / 提现 / 兑换进入资金页对应 Tab。点活动条提示「活动中心即将开放」。
  5. 左右滑动或点右下指示器切换 Banner；按住时暂停，默认约 4 秒轮播。第 1 张进邀请页，第 2 张进开播设置，第 3 张：未加入代理进代理邀请，已加入进代理中心。
  6. 点设置进设置页。底栏大厅 / 社区 / 会话 / 我的只在旗舰厅内切换。

三、视觉表现

  1. 页头浅石香槟过渡到灰底。资料区无独立底色；VIP 卡冰蓝（#f7f7f7 → #dcf2ff），左 VIP1、右 VIP2，不铺橙色。
  2. 钱包卡极浅暖白到浅杏，拉丝与噪点半透明，几乎不铺橙色；充值为主题橙钮，提现 / 兑换半透明白底。
  3. 活动条左浅杏底 + 礼盒文案，右浅珊瑚浪形「参与活动 ›」，不铺饱和红金。
  4. Banner 指示器在右下角横向排列。第 2 张铺招募主播整图（招募优质主播 / 最高分成可达 99% / 点击报名），不再叠文案。第 1 / 3 张为橙 / 金橙渐变卡。
  5. 颜色、字号以实际设计稿为准。

五、异常与边界

  1. 无独立扫码页、活动中心页时，分别提示「扫一扫即将开放」「活动中心即将开放」，不跳空白页。
  2. 复制金刚号失败时提示手动长按。刷新进行中再次点刷新不重复触发。
  3. 隐藏余额时总资产与冻结额度同时打码。冻结为 0 时仍展示「冻结额度 0.00」，不隐藏该行。
  4. 未加入代理不出现「代理中心」；已加入后不出现「代理邀请」。
