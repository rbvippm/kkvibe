# 占成 · 代理盈亏口径调整（实占净输赢 / 代理赚水）

给前端（可直接喂给 AI）。一次性改完：**公式、页面结构、点击入口、金额颜色、文案**。

只改 **占成身份** 的这些页面：

- 代理详情 · 代理盈亏
- 代理详情 · 游戏数据
- 我的报表 · 盈亏
- 我的报表 · 游戏

**不要改返佣「我的佣金」**、会员详情盈亏、PC 后台。返佣「游戏」本身就没有代理赚水，不要按占成旧公式加回去。

旧文档 `docs/代理盈亏公式-成本项正数减法.md` 里「代理赚水作为游戏净输赢成本项」的占成口径 **作废**，以本文为准。

---

## 1. 为什么改

以前占成：

- 游戏净输赢（含盈亏列表、游戏数据、游戏报表）都扣 **代理赚水**
- 顶部大数叫「总盈亏」，其实等于「游戏净输赢 − 其他成本」
- 代理赚水藏在游戏成本里，代理看不清自己赚了多少水钱

现在占成：

- **所有「游戏净输赢」都不再扣代理赚水**（盈亏页、游戏数据、游戏报表同一口径）
- 原「总盈亏 / 净盈亏」改名 **实占净输赢**
- **代理赚水** 只出现在盈亏页，作为总盈亏加项
- 新总盈亏 = 实占净输赢 + 代理赚水

---

## 2. 必须遵守的硬规则

1. **只改占成**。返佣佣金公式、级次 Tab、负盈利累计一律不动。
2. 凡是「游戏净输赢」公式 / 明细，**一律不含代理赚水**，仍含场馆费。
3. 代理赚水是 **利润加项**，不是成本。只出现在盈亏页，不出现在游戏数据 / 游戏报表。
4. 盈亏页金额列：游戏 / 其他成本叫「金额（实占）」；代理赚水叫「金额（利润）」。
5. 赚水明细里各游戏大类金额 **全部为正、绿色带 `+`**，不要套游戏净输赢的正负分布。
6. **代理赚水公式必须动态拼**，不要写死「刮刮乐 + 弹珠 + …」。游戏细项随后台产品开关展示，公式加项 = 当前展示的细项，顺序一致。
7. 成本项规则不变：服务端正数 → 列表绝对值粉色不带负号 → 公式用减法。
8. 公式文案禁止 `【】`，禁止 `+ 【-退水】`。
9. 代理详情「代理盈亏」= 我的报表「盈亏」；代理详情「游戏数据」= 我的报表「游戏」（占成）。
10. 盈亏页不要再把底部单独放一张公式卡。公式嵌在顶部总盈亏卡里。
11. 代理赚水展开后的大类金额 **可点**。弹框标题、末行、公式左侧统一写成 **「{大类名}赚水」**（如「刮刮乐赚水」「真人赚水」），不要写成「刮刮乐明细」或末行只写「刮刮乐」。
12. 总盈亏明细行与感叹号用 **展开式** `总盈亏 = 游戏净输赢 - 其他成本 + 代理赚水`。不要再把明细做成「实占净输赢 + 代理赚水」两行。

## 3. 公式清单

### 3.1 固定文案（直接用）

```
游戏净输赢 = 实占游戏输赢 - 实占退水 - 实占VIP退水 - 场馆费

其他成本 = VIP晋级礼金 + VIP额外奖金 + 活动金 + 充提手续费

实占净输赢 = 游戏净输赢 - 其他成本

实占净输赢 = 实占游戏输赢 - 实占退水 - 实占VIP退水 - 场馆费 - 实占VIP晋级礼金 - 实占VIP额外奖金 - 实占活动金 - 实占充提手续费

总盈亏 = 游戏净输赢 - 其他成本 + 代理赚水

总盈亏 = 实占净输赢 + 代理赚水
```

关系（两条总盈亏公式等价，用在不同位置）：

```
总盈亏
  = 游戏净输赢 - 其他成本 + 代理赚水     ← 总盈亏明细感叹号 / 经典汇总感叹号（展开式）
  = 实占净输赢 + 代理赚水               ← 顶部总盈亏卡内嵌公式（实占净输赢未展开）
```

| 位置 | 用哪条 |
|------|--------|
| 顶部总盈亏卡分割线内嵌 | `实占净输赢 + 代理赚水 = 总盈亏` |
| 总盈亏卡「实占净输赢」旁灰色感叹号 | `实占净输赢 = 游戏净输赢 - 其他成本` |
| 总盈亏明细末行感叹号 | `总盈亏 = 游戏净输赢 - 其他成本 + 代理赚水` |
| 实占净输赢明细末行感叹号 | 上面那条去掉代理赚水后的长公式 |

**禁止**再出现：

```
游戏净输赢 = … - 代理赚水 - 场馆费
总盈亏 = … - 代理赚水 …
总盈亏明细行做成「实占净输赢」「代理赚水」两行（应拆成游戏净输赢 / 其他成本 / 代理赚水 / 总盈亏）
```

### 3.2 代理赚水公式（动态，不要写死）

模板：

```
代理赚水 = {当前开启的游戏细项用「 + 」拼接}
```

规则：

1. 后台会按产品开关决定展示哪些游戏细项（刮刮乐 / 弹珠 / 棋牌 / 彩票 / 趣投 / 体育 / 真人 / 老虎机 / 捕鱼 / 以及后续新增品类）。
2. **明细行有哪些品类，公式加项就有哪些**，名称、顺序必须一致。
3. 关闭的品类：不出现在赚水明细、不出现在公式、不计入合计。
4. 只开 1 个时写成 `代理赚水 = 刮刮乐`（没有加号）。
5. 一个都没开：不展示赚水明细公式条；合计按 `0.00`。
6. 不要手写完整九项当最终文案。原型全开时的示例仅供对照：

```
代理赚水 = 刮刮乐 + 弹珠 + 棋牌 + 彩票 + 趣投 + 体育 + 真人 + 老虎机 + 捕鱼
```

实现：用当前列表的品类名 `join(' + ')`，前面加 `代理赚水 = `。

### 3.3 大类赚水公式（动态，点刮刮乐 / 真人等打开）

模板：

```
{大类名}赚水 = {该大类下当前开启的游戏名用「 + 」拼接}
```

规则：

1. 标题、末行、公式左侧 **同一文案**：`{大类名}赚水`。真人就是「真人赚水」，不要只写「真人」。
2. 等号右侧只拼 **该大类下当前后台开启的游戏**（`enabled !== false`），关闭的游戏不出现、不计入。
3. 游戏名保持场馆原名（如 IM真人、金刚真人），不要改成「IM真人赚水」。
4. 只开 1 个时写成 `刮刮乐赚水 = GGL刮乐`（没有加号）。
5. 一个都没开：不展示该大类行，也不进 3.2 的代理赚水公式。
6. 不要写死场馆清单。原型示例仅供对照：

```
刮刮乐赚水 = GGL刮乐 + 金刚刮刮乐 + 幸运刮刮乐
体育赚水 = IM体育 + 金刚体育 + SABA体育
真人赚水 = IM真人 + 金刚真人
```

实现：`joinProfitSumFormula(\`${categoryLabel}赚水\`, 当前开启游戏名)`。

## 5. 盈亏页结构（代理详情 · 代理盈亏 / 我的报表 · 盈亏）

从上到下：

1. 筛选条：日期 + 币种 + 今日 / 昨天 / 本月 / 上月
2. 团队充提两列卡：团队充值总额 / 团队提款总额（**不参与盈亏公式**；仅详情有）
3. **总盈亏浅暖色卡**（金币装饰）
   - 标题「总盈亏」+ 大号金额（正绿负粉）
   - 分割线下方内嵌公式，**不再另起公式卡**：

     `实占净输赢 + 代理赚水 = 总盈亏`

4. 分区卡「游戏净输赢 / 金额（实占）」
5. 分区卡「其他成本 / 金额（实占）」
6. 分区卡「代理赚水 / 金额（利润）」——必须在其他成本之后，最后一块
7. **没有** 底部公式卡

游戏净输赢、其他成本、代理赚水：首行「合计 ▾」可展开。游戏与代理赚水默认收起，其他成本默认展开。  
代理赚水展开后为游戏大类细项（均为正绿带 +）：

- **合计金额不可点、无下划线**（总赚水明细只从顶部公式「代理赚水」金额进）
- **大类金额可点、有下划线**，打开「{大类名}赚水」弹框（见 8.5）

## 6. 游戏数据 / 游戏报表（占成必改）

这两个页以前游戏净输赢会扣代理赚水，明细里也有「代理赚水」行。**全部删掉。**

### 6.1 范围

- 代理详情 Tab「游戏数据」（占成）
- 我的报表 Tab「游戏」（占成）
- 两页品类 / 场馆切换后的明细卡，同一口径

### 6.2 公式（感叹号 tip）

旧（不要再用）：

```
游戏净输赢 = 实占游戏输赢 - 实占退水 - 实占VIP退水 - 代理赚水 - 场馆费
```

新：

```
游戏净输赢 = 实占游戏输赢 - 实占退水 - 实占VIP退水 - 场馆费
```

与盈亏页点开游戏大类明细的公式一致。

### 6.3 明细行

| 行 | 是否保留 |
|----|----------|
| 下注有效金额 | 保留（黑色，不参与结算） |
| 输赢 / 实占游戏输赢 | 保留 |
| 退水 / 实占退水 | 保留 |
| VIP退水 / 实占VIP退水 | 保留 |
| **代理赚水** | **删除，整行不渲染** |
| 场馆费 | 保留 |
| 游戏净输赢（结果行） | 保留，按新公式算 |

结算：`游戏净输赢 = 输赢 - 退水 - VIP退水 - 场馆费`，**不要再减代理赚水**。

标题占成带「（实占）」，如「全部（实占）」「体育（实占）」。

返佣游戏页继续用自己的公式（无退水、无代理赚水、无「实占」），不要套占成这条。

### 7.3 明细弹框末行感叹号

| 明细 | 感叹号公式 |
|------|------------|
| 游戏大类 / 游戏数据 / 游戏报表 | `游戏净输赢 = 实占游戏输赢 - 实占退水 - 实占VIP退水 - 场馆费` |

| 代理赚水 | **动态**：`代理赚水 = ` + 当前开启大类名用 ` + ` 拼接 |

**不要**再写「代理赚水为退水利润，计入总盈亏加项」这种说明句。

## 8. 明细弹框内容

### 8.1 游戏大类明细（盈亏页点大类）

下注有效金额 / 输赢 / 退水 / VIP退水 / 场馆费 / 游戏净输赢  
**无代理赚水行。** 下注有效金额只展示，不参与结算。

### 8.2 实占净输赢明细

游戏净输赢构成项（实占游戏输赢、实占退水、实占VIP退水、场馆费）+ 其他成本细项 + 末行实占净输赢。

### 8.3 总盈亏明细

表头左列为 **「盈亏项」**（不要写「实占细项」），右列「金额」。

| 行 | 展示 | 说明 |
|----|------|------|
| 游戏净输赢 | 正绿负粉，带正负号 | 加项 |
| 其他成本 | 绝对值、粉色，不带负号 | 减项 |
| 代理赚水 | 正绿带 `+` | 加项 |
| 总盈亏（末行加粗） | 正绿负粉 | 感叹号：`总盈亏 = 游戏净输赢 - 其他成本 + 代理赚水` |

验算：`游戏净输赢 − 其他成本 + 代理赚水 = 总盈亏`（与顶部卡 `实占净输赢 + 代理赚水` 数值相同）。  
**不要**再做成「实占净输赢」「代理赚水」两行。

实占净输赢明细、游戏大类明细同样用「盈亏项 / 金额」。

### 8.4 代理赚水明细

- 表头左列为 **「游戏分类」**（不要写「实占细项」或「盈亏项」），右列「金额」
- 行 = **当前后台开启的游戏细项**（不是写死九行）
- 每行金额全部为正，绿色带 `+`
- 末行「代理赚水」合计 = 上面各行之和
- 感叹号公式按 3.2 动态拼接，与当前行一致
- 不要复用游戏净输赢的正负分布

### 8.5 代理赚水 · 大类赚水（点刮刮乐 / 真人等）

- **标题**：「{大类名}赚水」（刮刮乐赚水、弹珠赚水、真人赚水…）。**不要**写成「刮刮乐明细」
- 表头左列为 **「游戏」**，右列「金额」（不要写「盈亏项」或「游戏分类」）
- 行 = **该大类下当前后台开启的游戏**（不是写死场馆清单）
- 每行金额全部为正，绿色带 `+`
- **末行**「{大类名}赚水」合计 = 上面各游戏之和（真人末行写「真人赚水」，不要只写「真人」）
- **感叹号公式**与末行同一左侧文案：`{大类名}赚水 = 游戏1 + 游戏2 + …`（如 `真人赚水 = IM真人 + 金刚真人`）
- 关闭的游戏：不出现在明细、不出现在公式、不计入该大类合计
- 只开 1 个时写成 `刮刮乐赚水 = GGL刮乐`（没有加号）

## 9. 视觉

- 顶部大号总盈亏：正绿 `#18AF91`，负粉 `#F84473`
- **公式三项金额同样正绿负粉**，不要用黑色 / 深灰。标签保持灰色
- 总盈亏格浅绿底 `rgba(24, 175, 145, 0.08)`
- 可点金额带下划线；只读合计无下划线
- 实占净输赢旁感叹号：灰色圆圈 `i`，对齐游戏净输赢那套，不要用蓝色问号
- 分区表头暖色；代理赚水金额列表头文案是「金额（利润）」
- 赚水公式条可能比九项更短或更长，tip 要换行，不要截断

注意：如果总盈亏卡在列表 `main` 外面（报表页 hero 区常见），正负色 class 必须在公式金额上也能生效，不要只给表格 cell 上色。
