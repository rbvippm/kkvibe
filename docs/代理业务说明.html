一代理类型

口径：后台与代理端按 share / rebate 两套身份切能力。占成可发展多级团队；返佣只有一层直属会员，不发展下级代理，没有邀请。

1. 占成代理 / 退水

占成代理 · share

按实占分盈亏

  • 多级树形团队：直属会员 + 下级代理下会员一起算实占。
  • 收益两块：实占净输赢 + 代理赚水 = 总盈亏。
  • 信用：当前仅 x 币 授信、上下分；未来映射「信用额度-CNY」。USD / 双信用钱包未上线。
  • 现金币种：KKC / KKV / USDT。
  • 代理中心报表 Tab：盈亏 + 游戏。
退水 · 占成内机制

不是单独一种代理

  • 后台旧「赚水」已改成「退水」：填写值是向下级返还的退水比例。
  • 会员侧：「投注退水 / 会员退水」。代理侧：「代理赚水」（退水利润，为正数加项）。
  • 授信、创建、邀请（仅占成）时，占成与退水一起配。
  • 列表、筛选、账密里不要出现第三种代理类型。

2. 返佣代理

返佣代理 · rebate

一层直属，按月拿佣金

  • 固定一级，不发展下级代理，列表无上级。
  • 不配占成、不配退水、不授信、无上下分；无邀请、无邀请记录、不能创建下级代理。
  • 成为返佣代理只走 PC 后台；代理端只能创建直属会员。
  • 只统计直属会员；报表 Tab：佣金 + 游戏。
  • 佣金档位：当月团队净输赢门槛 + 活跃人数 → 命中佣金比例。
  • 公式：佣金 = max(净输赢 − 负盈利累计, 0) × 佣金比例。

二成为代理与开户

规则：占成有三条进线——后台创建、代理端创建下级代理、邀请已有会员。成为返佣代理只有后台创建。返佣团队页只能创建会员，不提供创建下级代理、邀请和邀请记录。

四结算与账单

结账：占成看日/月盈亏，交收走线下；退水跟投注走、按现金批次；返佣只月结，线上派发到现金钱包。

1. 占成：盈亏 + 赚水，会员退水，盈亏线下，退水按批次

盈亏 + 赚水

账单主结果是总盈亏，不是佣金。

总盈亏 = 实占净输赢 + 代理赚水

「我的盈亏」可按今天 / 昨天 / 本月 / 上月或自定义日期看。代理赚水按后台开启的游戏大类加总，项项为正。

会员退水

会员视角退水为正，进会员盈亏；代理视角「实占退水」从游戏净输赢里减。

概况有「投注退水」。会员退水比例可在代理端单独配。

结算对账

退水按批次

充值、取款、活跃是金刚实时。投注退水、VIP 退水、输赢、赚水是现金约 10 分钟一批。退水跟注单批次出，不做月结佣金。

2. 退水（占成内）：赚水，会员退水，按批次

这里是占成体系里的退水账，不是另一套代理后台。

  • 赚水：代理从团队流水拿到的退水利润，加进总盈亏，不加进游戏净输赢。
  • 会员退水：按退水比例返给会员，会员账单里是正项；代理报表里是实占退水减项。
  • 批次：跟注单走（约 10 分钟），不做月结佣金。
  • 比例来源：后台占成配置、代理端创建 / 授信、占成邀请时的收益比例、会员退水比例页。返佣不配退水、没有邀请。

3. 返佣：佣金月结，走线上

  • 只能选月份，不能按日。近 12 个结算月（含本月）。
  • 本月：待派发，看预计佣金；历史月：已派发 / 无佣金。
  • 累计发放只加「已派发」月。
  • 成为代理之前的月份显示「未入驻」，没有账单。
  • 冲减负盈利后为负，当月佣金按 0。
  • 线上派发到现金钱包，不走信用上下分。
佣金 = max(净输赢 − 负盈利累计, 0) × 当月档位佣金比例
