语聊房 · 角色权限与麦控规范

v1.1 范围：禁音 / 禁麦（不含弹幕） 更新：2026-05-28
说明：本文档中「禁言」均指 语音禁麦，不涉及公屏或弹幕文字禁言。房管 不可 设置/撤销房管，不可 踢房管下麦；对其它房管 仅可禁麦。任免房管、踢房管仅 房主 可操作。
礼物打赏：房主、房管、其他麦、观众 均可打赏；对象为房间内 所有在麦用户；不可打赏自己。

1. 适用范围

在范围内不在范围内
开麦/闭麦、单麦禁麦、全体禁麦 弹幕禁言、公屏文字管控
踢麦、下麦、换位、关闭麦位 聊天敏感词策略
房管任免（仅房主） —
礼物打赏（全角色、麦上全员、不可打赏自己） 对未上麦观众打赏（若产品不做）

2. 角色与身份来源

角色来源说明
房主创建房间1 号麦，不可换位
房管房主任命 / 后台管理权 < 房主
其他麦上麦后自控 + 互动
普通观众进房打赏、关注、申请上麦

权限层级：房主 > 房管 > 其他麦 > 普通观众

3. 角色能力清单

3.1 房主

  • 开麦/闭麦（自己及他人）
  • 踢麦（含踢房管）、关闭位子（2～N）、单麦禁麦、全体禁麦
  • 设置 / 撤销房管（独有）
  • 1 号麦不可换位；礼物打赏 / 关注（麦上全员，不含自己）

3.2 房管

  • 开麦/闭麦、踢麦（仅普通在麦用户）
  • 对其它房管：仅单麦禁麦，不可踢、不可任免
  • 下麦、换位（不含 1 号）、关闭位子（2～N）、全体禁麦
  • 不可设置/撤销房管 · 不可踢房管
  • 礼物打赏 / 关注（麦上全员，不含自己）

3.3 其他麦

  • 开麦/闭麦、下麦、换位（不可换入 1 号）
  • 礼物打赏 / 关注（麦上全员，不含自己）

3.4 普通观众

  • 礼物打赏 / 关注（麦上全员，不含自己）；满足条件可申请上麦

3.5 礼物打赏（全角色通用）

规则说明
可操作角色房主、房管、其他麦、观众 均可
可打赏对象房间内 所有在麦用户
禁止不可打赏自己
空麦位不可作为打赏目标
flowchart TD G[任意角色点击礼物] --> L[展示在麦用户列表] L --> F{目标是否为自己?} F -->|是| X[禁用 / ERR_GIFT_SELF] F -->|否| P[选择礼物并支付] P --> S[校验：目标在麦且非本人] S --> OK[打赏成功]

8. API 字段建议
