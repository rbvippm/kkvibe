统一场景示意 · 边视频聊天，边玩劈大话色

一、调研背景与目标

KK Vibe 的核心玩法是语聊房内的社交小游戏。以「劈大话色」为例：玩家需要一边视频连麦观察对手表情，一边同步进行骰子叫点、劈、开等操作。这类场景对音视频互动模式的选择有直接影响。

调研目标：
  • 在「劈大话色」场景下，三种音视频模式分别怎么玩、有什么限制
  • 明确 KK Vibe 应锚定哪种模式，以及需要补齐哪些能力

二、分析框架说明

权限控制 谁说了算 谁开局、踢人、暂停游戏、判定作弊？

技术侧重点 工程优先项 视频清晰度 vs 游戏低延迟 vs 万人围观分发

三、三种模式 × 劈大话色场景分析

以下均以同一局劈大话色为参照，看三种模式如何承载「视频 + 游戏」。

模式一

链接分享（Google Meet / Zoom / 腾讯会议）

怎么玩劈大话色：发起人创建会议 → 分享链接 → 朋友点链接加入 → 另开游戏 App 或共享屏幕玩骰子。视频和游戏是割裂的。

场景图 · 会议里「外挂」游戏
Google MeetZoom腾讯会议
  • 关系链：链接分享，半私密，适合已知朋友临时组局
  • 权限：Host 控麦控人，但无法控制游戏
  • 结论：能视频聊天，不适合原生嵌入劈大话色
模式二

好友通话（微信视频 / FaceTime）

怎么玩劈大话色：微信群里喊一声「来劈骰」→ 发起群视频 → 线下摇骰，或用小游戏小程序。视频是视频，骰子是骰子。

场景图 · 群视频 + 线下/小程序骰子
微信视频FaceTime
  • 关系链：强好友/群关系，极私密，组局靠喊
  • 权限：人人平等，没人能主持游戏公平性
  • 结论：适合熟人小局，无法支撑陌生人匹配 + 防作弊 + 打赏
模式三

直播连麦 / 语聊房（抖音 / KK Vibe）

怎么玩劈大话色：进语聊房 → 视频连麦 → 游戏区原生嵌入劈大话色 → 房主开局、控麦、围观者送礼物。视频与游戏一体，正是 KK Vibe 的主场景。

场景图 · 语聊房内原生劈大话色（KK Vibe 目标态）
抖音连麦B站直播KK Vibe ★
  • 关系链：大厅发现 or 链接入房，陌生人/半熟人皆可组局
  • 权限：房主开局/踢人/禁麦，游戏服务端统一仲裁骰子
  • 结论：最契合「边视频聊天，边玩劈大话色」—— KK Vibe 应锚定此模式
