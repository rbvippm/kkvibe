1. 背景与目标

三期在一期 / 二期能力之上，补齐成本占成配置，并统一 代理盈亏 / 会员盈亏 / 游戏净输赢 的细项展示与计算公式， 让代理端与 BI 后台对「实占成本」有一致口径。

业务目标

把 VIP 晋级礼金、VIP 额外奖金、活动金等纳入可配置的「其他成本」占成，并进入盈亏计算。

体验目标

报表、详情、我的盈亏等页面「游戏净输赢」细项对齐（含下注有效金额仅展示）；正绿负粉；公式 tip 可查。

管理目标

代理端与 BI 后台均可配置成本占成，上下级比例受上限约束。

4. 模块一：成本占成（其他成本）

「其他成本」用于承接原分散的成本类占成项： VIP 晋级礼金、VIP 额外奖金、活动金 合并为同一占成比例配置项， 在概况「占成比例」弹框中与各游戏品类并列展示。

4.1 代理端改造点

场景 交互说明
团队管理 · 新增代理 · 收益比例 在全局占成 / 退水滑块下方增加「其他成本」行（默认 0%，展示「最高 xx%」）； 点击数值或铅笔进入「编辑其他成本」底部弹层，取消 / 保存。
团队管理 · 收益比例 · 查看 & 修改 查看页展示只读其他成本；进入「设置现金比例」可编辑。 占成滑块可同步写入其他成本（不超过上级最大值）。
邀请现有会员成为下级 · 收益比例步 与新增代理一致，需填写其他成本后再确认邀请。
概况 · 占成比例弹框 表末增加「其他成本」行；只读确认，不提供编辑。 原型 Mock 示例：刮刮乐 2.5% … 捕鱼 0.5%，其他成本 1.0%。
编辑其他成本弹层 标题「编辑其他成本」；提示「最高 xx%」；输入百分比； 按钮「取消」「保存」。须为整数；超上限不可保存。

4.2 BI 后台改造点

BI 推广返利 / 占成代理配置 · 新增 & 编辑代理弹窗： 在各游戏品类占成网格中增加 其他成本（仅占成区展示，退水区不展示）。

品类示例：棋牌、趣投、电竞、捕鱼、刮刮乐、热门类、体育、真人、彩票、弹珠、老虎机、其他成本。

精度：代理端与 BI 的占成设置（含「其他成本」）均为整数； 区间 0～上级该品类最大值（maxShare）。退水仍按既有规则（可含小数）。

4.3 配置规则摘要

  • 代理端其他成本为全局整数比例，区间 0 ~ 上级最大值（原型 Mock 常见最高 10%）。
  • 拖动顶部「占成」滑块时，可同步写入其他成本（取 min(占成整数, 上级最大值)）。
  • 概况弹框中「其他成本」= VIP 晋级礼金 + VIP 额外奖金 + 活动金 的合并占成展示。

5. 模块二：盈亏细项区分

将「游戏净输赢（场馆 / 报表口径）」与「代理盈亏 / 会员盈亏（含成本项）」拆清： 成本三项（VIP 晋级礼金、VIP 额外奖金、活动金）只出现在盈亏汇总，不进入场馆游戏净输赢明细。

5.1 代理端 · 我的报表（占成）

  • 顶部仅保留充提 / 上下分三卡统计；不再展示「赚水 / 实占数据」汇总卡（盈亏汇总改由概况「我的盈亏」查看）。
  • 场馆明细标题行：感叹号 + 游戏净输赢 + 数值（正绿负粉）。
  • 明细行（自上而下）： 下注有效金额（黑色 / 中性，仅展示、不参与净输赢结算）→ 输赢 → 退水 → VIP退水 → 代理赚水（取负展示并参与结算）。
  • 不含 VIP 晋级礼金 / VIP 额外奖金 / 活动金。
  • 品类筛选交互见 §6（一级 / 二级均含「全部」）。
  • 原型 Mock：一级「全部」游戏净输赢为 +10,060.00（验算：12350 − 1280 − 150 − 860）。

5.2 代理端 · 代理详情（占成）

  • 代理盈亏 Tab：首行总值 + tip；细项七项—— 输赢、退水、VIP退水、代理赚水、VIP晋级礼金、VIP额外奖金、活动金 （展示名不带「实占」前缀；公式 tip 仍用【实占…】）。
  • 游戏数据：一级品类 Tab（含「全部」）+ 二级场馆 pill（含「全部」）； 一级「全部」时不展示二级；明细与「我的报表」游戏净输赢口径一致 （含下注有效金额仅展示、代理赚水取负，不含成本三项）。 完整交互见 §6。

5.3 代理端 · 会员详情（占成）

  • 会员盈亏：首行总值 + tip；细项六项—— 游戏输赢、会员退水、VIP退水、VIP晋级礼金、VIP额外奖金、活动金 （会员侧退水 / 礼金按公式直接累加，展示为正贡献时用绿色）。
  • 游戏数据 · 游戏统计：标题行「游戏净输赢」+ tip； 明细为下注有效金额（仅展示）→ 输赢 → 会员退水 → VIP退水 → 代理赚水（取负）； 品类筛选同 §6。

5.4 代理端 · 我的盈亏（概况入口 · 占成）

  • 顶部总盈亏（即代理盈亏口径），无感叹号 tip。
  • 列表：各游戏占成项 + VIP晋级礼金 + VIP额外奖金 + 活动金 + 总计；代理赚水不单独成行。
  • 点击游戏占成项 →「{品类}盈亏明细」： 下注有效金额（仅展示）→ 输赢 → 退水 → VIP退水 → 代理赚水 → 游戏净输赢（末行结果）； 表头「实占细项 / 金额」。
  • 点击总计 →「总计盈亏明细」（代理盈亏七项 + 末行「代理盈亏」结果）。
  • 明细弹框内：末行结果项旁感叹号；公式说明在表格与「我知道了」按钮之间展开（避免气泡裁切）。
  • 底部说明： 数据每十分钟更新一次 / 最多可查询近 6 个月的数据。

6. 品类筛选（一级 / 二级「全部」）

通用规则（我的报表 / 代理详情·游戏数据 / 会员详情·游戏统计 三端一致）。 Review 遗漏补丁：游戏一级分类与二级分类切换都要有「全部」。

  • 一级品类 Tab 必须含「全部」（各品类合计）； 进入页面默认选中一级「全部」。
  • 二级场馆 pill 必须含「全部」（该品类合计）； 仅当一级为具体品类时展示二级。
  • 一级选中「全部」时：隐藏二级场馆分类； 切回一级「全部」时二级隐藏，并将场馆状态重置为「全部」。
  • 切换一级品类时：二级默认选中「全部」，再刷新下方明细卡。
  • 一级「全部」无场馆子项；分品类下始终含二级「全部」及各场馆 （如体育：全部 / IM体育 / 金刚体育 / SABA体育 / CDN体育 等）。
一级选中 二级场馆 pill 明细含义
全部 不展示 各品类合计游戏净输赢
具体品类（如体育） 展示，首项「全部」，默认选中「全部」 该品类合计；点具体场馆后为单场馆

品类清单可按端 Mock 略有差异：我的报表一级为 全部 / 棋牌 / 电竞 / 捕鱼 / 老虎机 / 体育； 代理详情 / 会员游戏统计可含真人、弹珠、刮刮乐、彩票等， 但不影响「一级 / 二级均含全部」的交互规则。

7. 统一公式与字段口径

7.1 游戏净输赢（报表 / 游戏数据 / 占成项明细）

适用范围（占成）：我的报表场馆卡、代理详情·游戏数据、会员详情·游戏统计、我的盈亏·游戏占成项弹框。

游戏净输赢 = 【实占游戏输赢】 + 【-实占退水】 + 【-实占VIP退水】 + 【-代理赚水】

会员游戏统计公式文案：

游戏净输赢 = 【游戏输赢】 + 【-会员退水】 + 【-VIP退水】 + 【-代理赚水】
  • 页面标题与公式左侧文案统一为「游戏净输赢」（不再使用「游戏盈亏」等旧称）。
  • 明细首行「下注有效金额」仅展示、不参与游戏净输赢计算；金额中性黑色，无正负色。
  • 明细行短标签：输赢 / 退水 / VIP退水 / 代理赚水（会员侧退水为「会员退水」）；公式 tip 使用【实占…】或【会员…】前缀。
  • 「代理赚水」在明细中取负展示，并计入游戏净输赢。
  • 不含 VIP晋级礼金、VIP额外奖金、活动金（成本三项仅出现在代理盈亏 / 会员盈亏）。

7.2 代理盈亏（代理详情 / 我的盈亏总计）

代理盈亏 = 【实占游戏输赢】 + 【-实占退水】 + 【-实占VIP退水】 + 【-代理赚水】 + 【-实占VIP晋级礼金】 + 【-实占VIP额外奖金】 + 【-实占活动金】

7.3 会员盈亏（会员详情）

会员盈亏 = 【游戏输赢】 + 【会员退水】 + 【VIP退水】 + 【VIP晋级礼金】 + 【VIP额外奖金】 + 【活动金】

会员详情汇总 会员盈亏 会员盈亏；项内用【游戏输赢】等
场馆 / 报表明细 游戏净输赢 游戏净输赢

9. 数据规则与异常

9.1 展示规则

  • 盈亏类金额：正数青绿、负数玫红、中性黑；带 + / - 符号。
  • 金额默认不展示币种符号；随顶栏全局币种切换刷新统计。
  • 品类筛选完整规则见 §6（一级 / 二级均含「全部」；一级全部时隐藏二级）。
  • 游戏净输赢不含成本三项；代理盈亏含成本三项与代理赚水。
  • 游戏净输赢明细首行「下注有效金额」始终展示（含 0.00），中性黑色，不参与正负色与公式结算。

9.2 校验与边界

  • 其他成本非整数 / 超上限 → 弹层内提示，不可保存。
  • 无 Mock 明细的场馆 → 展示 0.00 / +0.00，不隐藏字段行（含下注有效金额）。
  • 我的盈亏查询窗口：最多近 6 个月；数据约每十分钟更新。
  • VIP 晋级礼金 / VIP 额外奖金 / 活动金在「我的盈亏」列表不可点开明细。

10. 验收要点

  1. 代理端四处（新增、邀请、收益比例、概况弹框）均可看到「其他成本」，且上限与同步规则正确。
  2. BI 编辑代理弹窗可见「其他成本」；占成（含其他成本）为整数，区间 0～上级上限。
  3. 代理盈亏 tip 文案含 实占游戏输赢，且七项齐全； 游戏净输赢 tip 为 游戏净输赢 = 【实占游戏输赢】 + 【-实占退水】 + 【-实占VIP退水】 + 【-代理赚水】， 含代理赚水、不含成本三项。
  4. 占成游戏净输赢明细（报表 / 代理游戏数据 / 会员游戏统计 / 我的盈亏占成项弹框）均含首行「下注有效金额」， 且该行不参与净输赢结算；会员游戏统计含「代理赚水」，标题为「游戏净输赢」。
  5. 我的报表不再出现「赚水 / 实占数据」汇总卡。
  6. 我的盈亏底部说明为「数据每十分钟更新一次」。
  7. 正负金额颜色在报表、详情、盈亏弹框均生效，不被基础字色覆盖；下注有效金额保持黑色。
  8. 品类「全部」：一级、二级均有「全部」；进入默认一级「全部」且二级隐藏； 切到具体品类后二级出现且默认「全部」；切回一级「全部」后二级再次隐藏。 （报表 / 代理详情游戏数据 / 会员游戏统计均需验收。）
