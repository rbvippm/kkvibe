# 代理盈亏 / 佣金公式变更（成本项改正数减法）

给前端（可直接喂给 AI）。一次性改完：**公式文案、加减运算、列表金额展示、明细弹框回算**。

---

## 1. 为什么改

以前服务端字段**自己带正负号**，公式全是加号，成本写在括号里：

```
游戏净输赢 = 【实占游戏输赢】 + 【-实占退水】 + 【-实占VIP退水】 + 【-代理赚水】 + 【-场馆费】
```

现在服务端成本项**全部给正数**。公式必须按真实加减写，并**去掉所有 `【】`**。

---

## 2. 必须遵守的硬规则

1. **不要**再把成本字段取负之后，又在公式里减一次（会减两次）。
2. 公式文案**禁止** `【】`，禁止 `+ 【-退水】` 这种写法。
3. **代理侧成本项**：公式用 `-`；列表展示**绝对值、粉色、不带负号**（例：`1,280.00`）。
4. **会员侧奖励项**：公式用 `+`；列表展示**正数、绿色、带 `+`**（例：`+120.00`）。
5. **输赢 / 游戏净输赢 / 总盈亏 / 佣金结果**：可正可负，正绿负粉，带 `+` / `-`。
6. **下注有效金额**：只展示，不参与结算；黑色、无正负号。
7. 同一字段在代理侧和会员侧符号**相反**：
   - 代理看 VIP退水 = 成本（减、粉）
   - 会员看 VIP退水 / 会员退水 = 奖励（加、绿）
8. **负盈利累计**不是成本字段，仍按累计值带负号展示（例：`-100.00`）。

---

## 3. 字段分类（按展示与运算）

### 3.1 代理成本项（服务端正数 → 展示绝对值粉色 → 公式减法）

- 退水 / 实占退水
- VIP退水 / 实占VIP退水 / 团队VIP退水
- 代理赚水
- 场馆费
- VIP晋级礼金 / 实占VIP晋级礼金
- VIP额外奖金 / 实占VIP额外奖金
- 活动金 / 实占活动金
- 充提手续费 / 实占充提手续费

其他成本合计 = 以上礼金/奖金/活动金/手续费的**正数相加**，再从游戏净输赢中减去。

### 3.2 会员奖励项（服务端正数 → 展示正绿带 + → 公式加法）

- 会员退水
- VIP退水（会员视角）
- VIP晋级礼金 / VIP额外奖金 / 活动金（会员「其他奖励」）

### 3.3 可正可负项

- 输赢 / 游戏输赢 / 实占游戏输赢 / 团队游戏输赢
- 游戏净输赢
- 总盈亏 / 代理盈亏 / 会员盈亏
- 当月佣金 / 总佣金

---

## 4. 公式清单（最终文案，直接用）

### 4.1 占成代理

```
游戏净输赢 = 实占游戏输赢 - 实占退水 - 实占VIP退水 - 代理赚水 - 场馆费

总盈亏 = 游戏净输赢 - 其他成本
其他成本 = VIP晋级礼金 + VIP额外奖金 + 活动金 + 充提手续费

代理盈亏 = 实占游戏输赢 - 实占退水 - 实占VIP退水 - 代理赚水 - 场馆费 - 实占VIP晋级礼金 - 实占VIP额外奖金 - 实占活动金 - 实占充提手续费
```

直属/下级等字段定义口径（无「实占」前缀时）：

```
游戏净输赢 = 游戏输赢 - 退水 - VIP退水 - 代理赚水 - 场馆费
代理盈亏/净输赢 = 游戏输赢 - 退水 - VIP退水 - 代理赚水 - 场馆费 - VIP晋级礼金 - VIP额外奖金 - 活动金 - 充提手续费
```

### 4.2 返佣代理

```
游戏净输赢 = 团队游戏输赢 - 团队VIP退水 - 场馆费

净输赢 = 游戏净输赢 - 其他成本
其他成本 = VIP晋级礼金 + VIP额外奖金 + 活动金 + 充提手续费

佣金 = （输赢 - VIP退水 - 场馆费 - VIP晋级礼金 - VIP额外奖金 - 活动金 - 充提手续费） × 佣金比例
当月佣金 = max(净输赢, 0) × 佣金比例
总佣金 = 当月佣金 - 负盈利累计   （仅待派发月展示负盈利累计；已派发月：总佣金 = 当月佣金）

代理佣金 = 输赢 - VIP退水 - 场馆费 - VIP晋级礼金 - VIP额外奖金 - 活动金 - 充提手续费
```

返佣游戏明细**没有**投注退水、**没有**代理赚水；标题**不加**「（实占）」。

当月总盈利（佣金比例设置表头 tip）：

```
= 输赢 - VIP退水 - 场馆费 - VIP晋级礼金 - VIP额外奖金 - 活动金 - 充提手续费
```

### 4.3 会员（占成）

```
游戏净输赢 = 游戏输赢 + 会员退水 + VIP退水
其他奖励 = VIP晋级礼金 + VIP额外奖金 + 活动金
会员盈亏 = 游戏净输赢 + 其他奖励
会员盈亏 = 游戏输赢 + 会员退水 + VIP退水 + VIP晋级礼金 + VIP额外奖金 + 活动金
```

明细含：下注有效金额、输赢、会员退水、VIP退水、游戏净输赢。  
**不含**代理赚水、场馆费；标题**不加**「（实占）」。

### 4.4 会员（返佣）

```
游戏净输赢 = 游戏输赢 + VIP退水
```

**不含**会员退水、代理赚水、场馆费。VIP 退水对会员为正绿。  
返佣原型通常隐藏「会员盈亏」Tab，不强制露出。

## 6. 大类明细回算（净输赢为负时必须这样）

列表上某个大类（如弹珠）的「游戏净输赢」可以为负。  
**禁止**把基准明细（输赢、退水…）整体按同一个负数比例缩放，否则会员退水会变红、代理成本会和公式对不上。

### 6.1 代理侧（成本为正，减法）

已知该大类 `targetNet`（列表金额），以及基准构成的绝对值权重。

```
成本合计 = Σ(各成本项绝对值 × |targetNet| / |基准净输赢|)
输赢 = targetNet + 成本合计
游戏净输赢 = 输赢 - 成本合计   // 必须等于 targetNet
```

- 输赢：按正负着色
- 成本项：始终正数粉色
- 末行游戏净输赢：等于该大类列表金额

### 6.2 会员侧（奖励为正，加法）

```
会员退水、VIP退水 = 各自基准绝对值 × |targetNet| / |基准净输赢|   // 始终 ≥ 0
输赢 = targetNet - 会员退水 - VIP退水
游戏净输赢 = 输赢 + 会员退水 + VIP退水   // 必须等于 targetNet
```

- 输赢：按正负着色
- 会员退水 / VIP退水：始终正绿带 `+`
- 末行游戏净输赢：等于该大类列表金额

示例（弹珠列表净输赢为负）：

- 错误：输赢 `-58.72`、会员退水 `-11.74`、VIP退水 `-5.88`、净 `-76.34`（三项全负，加号公式不成立）
- 正确：退水仍为正绿；输赢更负；三者按 `输赢 + 退水 + VIP退水` 加回列表净输赢

## 7. 金额展示约定

| 场景 | 格式 | 颜色 |
|---|---|---|
| 下注有效金额 | `1,280.00` | 黑 / 中性 |
| 代理成本项 | `1,280.00`（无符号） | 粉 / negative |
| 会员奖励项 | `+1,280.00` | 绿 / positive |
| 输赢、净输赢、盈亏、佣金 | `+1,280.00` 或 `-1,280.00` | 正绿负粉 |
| 0 | `0.00` | 中性 |
| 其他成本公式卡减数格 | 绝对值，配合运算符 `−` | 按设计（通常无 `+`） |
| 负盈利累计 | `-100.00` | 粉 |

千分位 + 两位小数。

## 8. 给 AI 的实现提示

- 先全局搜：`【`、`+ 【-`、`【-退水】`、`【-VIP`、`【-场馆费】`、`【-代理赚水】`，公式文案全部替换为第 4 节。
- Mock / 接口映射：成本字段按**正数**存；展示层不要再 `format(-cost)`。
- 结算层：`net = win - rebate - vipRebate - earn - venueFee`（代理）；会员 `net = win + memberRebate + vipRebate`。
- 大类弹框不要用「所有行乘以同一个符号系数」；用第 6 节拆分。
- 字段定义页、PRD 标注、tip 气泡三处文案必须一致。
