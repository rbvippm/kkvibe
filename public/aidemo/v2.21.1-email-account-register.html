金刚 · 账号体系升级需求

本次升级围绕「多种注册方式 + 手机号后置绑定」展开，涉及 客户端 的注册/登录/提现绑定流程，以及 后台管理系统 用户管理模块的字段补充。下方两个标签页为可交互原型。

后台原型参照真实系统 金刚后台管理系统 · 用户管理-用户列表 的布局与样式绘制（Element UI 风格，主色 #409EFF）。

一、客户端改动

1 新增两种注册方式

  • 手机号注册（原有）：手机号 → 短信验证码 → 完成
  • ＋ 邮箱注册（新增）：邮箱 → 邮箱验证码 → 完成
  • ＋ 账号密码注册（新增）：账号(6-20位含字母数字) → 设置密码 → 完成，无需手机号
  • 手机号 / 邮箱注册均自动生成唯一账号（KKxxxxxx），便于账号密码登录

2 登录方式适配

  • 账号密码登录：单输入框（账号 / 手机号 / 邮箱）+ 密码
  • 验证码登录：单输入框（手机号 / 邮箱），发送验证码
  • 国家码自动识别：不再手动切换标识类型，系统根据输入内容自动判断——输入纯数字视为手机号并自动显示国家码选择器；输入含字母或 @ 视为账号 / 邮箱并隐藏国家码
  • 凡邮箱输入均做正则校验（见下方校验规则）

3 提现绑定手机号

  • 提现时校验是否已绑定手机号，未绑定则必须先绑定
  • 绑定目标始终是手机号（必填）
  • 验证码可选手机短信或邮箱接收；选邮箱时仍需填写手机号
  • 选邮箱收码时：若用户已绑定邮箱则自动带出且不可修改；未绑定则要求输入邮箱（正则校验）
  • 提交时校验该手机号是否已被其他账号绑定

＋ 忘记密码 / 重置密码

  • 登录页「忘记密码」进入，选择 手机号 / 邮箱 接收验证码验证身份
  • 验证通过后进入重置密码页，设置新密码（8-20位含字母数字）→ 返回登录
  • 重要提示（页面展示）：如果账号未绑定手机号或邮箱，则需联系客服重置密码

✓ 输入校验规则

  • 邮箱：所有输入邮箱的位置（注册 / 登录 / 找回密码 / 绑定 / 收码）统一使用正则校验，格式 ^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$
  • 账号：仅允许字母和数字的组合，长度 6-20 位，且需同时包含字母与数字，不支持其他字符
  • 手机号：需选择国家码，仅数字
✔ 关键点：账号方式注册的用户初始无手机号，其手机号在「提现」环节按需绑定；无论用哪种渠道收验证码，被绑定的对象都是手机号，且需保证手机号唯一。

二、账号与安全（个人中心）

新增「账号与安全」页面，集中管理账号、手机号、邮箱与密码。用户除了在提现时被动绑定手机号外，也可在此主动绑定 / 换绑手机号、绑定 / 换绑邮箱、查看并修改登录账号。

＋ 绑定手机号 / 邮箱（绑定后锁定）

  • 绑定手机号：目标为手机号（必填），验证码可选手机短信或邮箱接收；提交校验手机号是否已被占用
  • 选邮箱收码时：已绑定邮箱自动带出且不可修改；未绑定则要求输入邮箱（正则校验）
  • 绑定邮箱：输入邮箱（正则校验）→ 邮箱验证码 → 完成；校验邮箱是否已被占用
  • 已绑定展示脱敏值（186****1002 / a***@x.com）并加🔒；手机号 / 邮箱一经绑定不可修改，需变更请联系客服

＋ 账号显示与修改（可多次）

  • 账号与安全页显示当前登录账号（账号注册的自定义账号 / 手机·邮箱注册生成的 KKxxxxxx）
  • 支持修改账号：输入新账号，校验 仅字母+数字组合、6-20位 与全局唯一性
  • 修改账号前需验证登录密码：提交时校验用户当前登录密码，密码正确才允许修改，密码错误则拦截并提示
  • 账号可多次修改，修改后旧账号立即释放
  • 修改成功后可用新账号登录，后台用户列表 / 详情同步展示最新账号
✔ 关键点：账号可多次修改（仅字母+数字、唯一），修改前需验证登录密码；手机号 / 邮箱绑定即锁定不可改；绑定手机时选邮箱收码，已绑邮箱自动带出、不可编辑。

三、后台改动（用户管理）

位置改动内容
用户列表 · 表格新增 账号、邮箱 两列：账号展示登录账号（自定义 / KKxxxxxx）；邮箱展示绑定邮箱，未绑定显示「-（未绑定）」，与手机号码并列
用户列表 · 搜索搜索条件新增 账号、邮箱 两个输入框，支持精确 / 模糊查询，可与其他条件组合
用户详情 · 用户信息详情字段中 账号、邮箱 高亮标记（✦），与手机号、金刚号等并列展示；邮箱未绑定时显示「未绑定」
邮箱 · 脱敏展示后端脱敏 列表与详情展示的邮箱由后端做脱敏处理：仅保留本地名前 4 位与 @ 之后的完整内容，中间统一用 四个星号 **** 代替。例：jimmyw2024@gmail.com → jimm****@gmail.com。搜索仍按完整邮箱匹配，前端不接触明文

说明：原后台已有「用户ID / 金刚号 / 手机号码」等标识，但缺少与新注册体系对应的登录账号与邮箱字段。本次在列表、搜索、详情三处补齐账号与邮箱，便于客服 / 运营按账号或邮箱定位用户。

四、账号字段定义

字段来源说明
账号 新增注册时确定用户唯一登录账号，仅字母+数字组合、6-20位。账号注册＝用户自定义；手机/邮箱注册＝系统生成 KK+6位。全局唯一，可多次修改（修改前需验证登录密码）
手机号码注册 / 提现绑定 / 账号与安全绑定账号注册用户初始为空，可在提现或账号与安全页绑定；绑定后不可修改；唯一
邮箱邮箱注册 / 账号与安全绑定邮箱注册用户填写，其余用户可在账号与安全页绑定；绑定后不可修改；唯一。所有输入处均正则校验
金刚号 / 用户ID系统生成原有系统标识，保持不变
