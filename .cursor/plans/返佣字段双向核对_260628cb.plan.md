## 1. 字段定义缺 / Axure 不完整（建议新建返佣字段定义时补齐）

### 我的直属
- VIP退水 / VIP晋级礼金 / VIP额外奖金：Axure **仅有字段名，无业务口径/维度** → 按概况直属口径补全
- 「充值金额」→ 对齐原型「**充值总额**」
- Axure「游戏净输赢 / 净输赢」公式含退水、代理赚水 → **改写为返佣原型口径**（见下）

### 我的报表-佣金（Axure 几乎无口径）
按原型补全业务说明（对齐 [`agentMyProfit.ts`](src/constants/agentMyProfit.ts)）：
- 佣金比例、预计佣金、负佣金累计、游戏净输赢、其他成本、净输赢、总佣金
- 核心公式写入字段定义：
  - `游戏净输赢 = 【团队游戏输赢】 + 【-团队VIP退水】 + 【-场馆费】`
  - `佣金 = （【输赢】 + 【-VIP退水】 + 【-VIP晋级礼金】 + 【-VIP额外奖金】 + 【-活动金】 + 【-充提手续费】） × 佣金比例`
  - `总佣金 = 当月佣金 - 负佣金累计`（待派发月）

### 我的报表-游戏
- 「游戏净输赢」Axure 缺统计方式/处理方，且公式仍是占成式 → 对齐原型（无退水、无代理赚水；标题不加「实占」）
- 业务口径中「直属 + 所有下级代理会员」与统计维度「仅直属」在 Axure 自相矛盾 → **以原型展示为准**写清：返佣团队管理仅直属会员，汇总卡文案沿用「团队充值/提款总额」

### 公式汇总区
- 去掉占成「实占」套话，改为返佣现行公式（游戏净输赢 / 佣金 / 总佣金 / 会员侧口径）

### 场景说明
- 与占成页已改口径一致：去掉「直属会员 Bu2」，统计改为 `Au2 + A2`（避免复制 Axure 旧场景）

## 2. 文案 / 公式不一致（字段定义跟随原型）

| 位置 | Axure | 返佣原型 | 建议 |
|---|---|---|---|
| 我的直属 | 充值金额 | 充值总额 | 字段定义用「充值总额」 |
| 概况/报表游戏净输赢 | 含退水、代理赚水 | 输赢 − VIP退水 − 场馆费 | 字段定义改返佣公式 |
| 会员详情游戏净输赢 | 含会员退水、代理赚水 | **无会员退水、无代理赚水** | 字段定义改：`游戏输赢 − VIP退水 − 场馆费` |
| 公式区会员盈亏 | 六项加法 | 原型新样式为「游戏净输赢 + 其他奖励」；且 **会员盈亏 Tab 隐藏** | 字段定义写现行口径，并注明原型隐藏 Tab |
| 我的 | 我的佣金 | 我的佣金 / KKC·KKV·USDT 总佣金 | 字段定义可补充「分币种总佣金」说明 |

## 3. 字段定义有、原型无/隐藏（不强制改原型）

| Axure / 拟字段定义 | 原型现状 | 建议 |
|---|---|---|
| 会员详情 · 会员盈亏 / 其他奖励 | 返佣身份 **隐藏会员盈亏 Tab** | 字段定义保留（产品口径），**不**重新打开 Tab |
