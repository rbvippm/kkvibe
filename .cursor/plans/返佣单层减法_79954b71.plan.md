# 返佣代理单层化减法计划

## 产品口径（已确认）

- 返佣代理只有一层（仅一级），不再发展下级代理。
- PC「返佣金设置」：**额外佣金**整块删除，**下级创建开关**一并删除；保留币种 + 当月佣金档位。
- 移动端返佣：**仅保留创建会员**；去掉创建代理 / 邀请现有会员为下级（及相关入口）。
- 「我的佣金」：**只保留直属佣金**；仅一级时 **去掉级次 Tab**。
- **占成（share）路径整段不动**；一级「代理赚水」仍保留（与多级额外佣金无关）。
